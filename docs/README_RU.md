# PolyTrade Terminal - Overview (RU)

## Что это
PolyTrade Terminal - это AI-ориентированный терминал для анализа prediction markets с explainable forecast-пайплайном.

## Текущий статус
- Реализован стабильный binary baseline.
- Реализован Phase 2B multi-outcome контур (contract, consensus, edge, UI, readiness).
- Активная разработка продолжается.
